プライバシーポリシー

最終更新日：2026年11月9日

「タイ語単語帳」（以下「本サービス」）における個人情報の取り扱いについて説明します。

1. 無料でお使いの場合

個人情報を一切取得しません。アカウント登録も不要です。

学習の進捗・お気に入り・設定は、お使いの端末の中（ブラウザのローカル保存領域）だけに保存されます。 運営者はこれらを見ることができません。 ブラウザの履歴やサイトデータを消去すると、学習記録も消えます。

2. アカウントを作成した場合

複数の端末で学習記録を同期するために、次の情報をお預かりします。

  • メールアドレス … 本人確認とログインのため
  • 学習記録 … 単語ごとの学習状況、お気に入り、表示設定

これらは認証とデータ同期の基盤である Supabase（Supabase Inc.）のサーバーに保存されます。 保存先のリージョンは日本（東京）です。

学習記録は、同期以外の目的には使いません。内容を分析したり、第三者に提供したりすることはありません。

3. お支払いに関する情報

決済は Paddle.com Market Ltd. が販売事業者として取り扱います。

クレジットカード番号などの支払い情報を、運営者が受け取ることはありません。 運営者が知りうるのは、購読が有効かどうか・プランの種類・更新日といった情報のみです。

Paddle における個人情報の取り扱いは、 Paddle のプライバシーポリシーをご確認ください。

4. 外部サービスへの通信

  • GitHub Pages … 本サービスの配信に使用しています。アクセスに伴う技術的な記録が GitHub 側に残る場合があります。
  • Google Fonts … 書体の読み込みに使用しています。
  • 端末の音声読み上げ機能 … タイ語の発音再生に、お使いの端末の機能を利用します。 音声データを外部に送信することはありません。

5. アクセス解析・広告

アクセス解析ツールは使用していません。広告も掲載していません。 行動履歴を追跡するクッキーも使用していません。

ログイン状態の保持と学習記録の保存のために、ブラウザのローカル保存領域を使用します。 これは本サービスを動かすために必要なもので、第三者には共有されません。

6. 保存期間と削除

アカウントを削除すると、メールアドレスと学習記録はサーバーから削除されます。 削除のご依頼はお問い合わせ先までお願いします。

有料プランを解約されただけの場合、学習記録は残ります （再開されたときに続きから使えるようにするためです）。 不要であれば削除をご依頼ください。

7. お子さまの利用について

本サービスは年齢を問わずご利用いただけますが、 13歳未満の方がアカウントを作成される場合は、保護者の方の同意を得てください。

8. ポリシーの変更

内容を変更する場合は、このページの最終更新日を改めてお知らせします。 重要な変更の場合は、アカウントをお持ちの方にメールでご連絡します。

9. お問い合わせ

個人情報の開示・訂正・削除のご依頼、その他のご質問は thaivocabmid@gmail.com までお願いします。
