# タイ語単語帳

タイ語検定（実用タイ語検定試験）対策の単語帳ウェブアプリ。基礎から1級まで5,263語。

- 公開URL: https://<ユーザー名>.github.io/<リポジトリ名>/
- アプリ本体: `app.html`（単一HTML・PWA・オフライン動作）

## このリポジトリについて

**配信用の成果物だけ**を置いています。語彙データの生成スクリプトや
開発用のファイルは別の非公開リポジトリで管理しています。

| ファイル | 内容 |
|---|---|
| `index.html` | 紹介ページ |
| `app.html` | アプリ本体（無料版） |
| `terms.html` / `privacy.html` | 利用規約・プライバシーポリシー |
| `manifest.json` / `service-worker.js` | PWA 用 |
| `icons/` | アプリアイコン |

## 意図的に置いていないもの

有料プラン向けの例文・構成要素データ（約1.8MB）は、このリポジトリにも
`app.html` にも含まれていません。購読が有効な利用者にだけ、認証付きの
API から配信します。

## 更新手順

`app.html` を差し替えるときは、`service-worker.js` の `CACHE_VERSION` を
必ず上げてください。上げないと、ホーム画面に追加済みの端末で
古い内容が表示され続けます。
